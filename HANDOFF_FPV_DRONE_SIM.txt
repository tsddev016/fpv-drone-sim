2. CONTROLES (COMO DEVEM FUNCIONAR)
================================================================================

ALTURA — 3 estados:
  SOBE  = climb +1
  PARA  = climb  0  (neutro / hover — NÃO subir sozinho)
  DESCE = climb -1

Touch: 3 botões na direita (SOBE | PARA | DESCE)
Teclado: PageUp = sobe | Home = para | PageDown = desce
Gamepad:
  R1 = SOBE
  R2 = DESCE
  L3 (clique stick esquerdo) = PARA
  L1 = FREIO DE AR (segura) — NÃO controla altura
  L2 = TURBO (segura) — NÃO controla altura
  Q = freio | E = turbo (teclado)

IMPORTANTE:
  L1/L2 NÃO podem fazer a mesma coisa que R1/R2.
  No neutro (PARA), o drone deve pairar, não subir infinito.

Sticks:
  Esquerdo: yaw / movimento
  Direito: pitch / roll

Menu:
  D-pad move cursor virtual | A confirma | B volta


================================================================================
3. FÍSICA DE VOO
================================================================================

- Modo ACRO (padrão): rates altos (~1400°/s), 360°, flips
- Modo ANGLE: limita inclinação
- No ACRO, NÃO aplicar limitação de angle
- Cambalhota → perde velocidade
- Mergulho → ganha velocidade horizontal
- Subindo → perde velocidade horizontal
- Vento dinâmico (modo Ultra)
- Freio L1: amortece velocity + angularVelocity
- Turbo L2: empurra na direção forward
- Colisão chão + prédios (sphere-AABB)

Flags globais:
  window.__FPV_CLIMB, __FPV_THROTTLE, __FPV_AIRBRAKE, __FPV_TURBO
  window.__FPV_WIND, __FPV_DRONE, __FPV_SCENE, __FPV_CAMERA
  window.__FPV_AFTER_MAP, window.__FPV_CAM_HIT, window.THREE
